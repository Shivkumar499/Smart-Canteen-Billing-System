
# Smart Canteen Billing System

## About the Project
Smart Canteen Billing System is a Python-based mini project that helps manage food orders and calculate bills in a canteen.

It allows customers to select food items, enter quantities, and receive a bill with applicable discounts.

## Features
- Display available food items
- Select food items and quantities
- Calculate subtotal
- Apply discounts based on the order amount
- Generate a final bill
- Display an itemized receipt
- Show the final amount payable

## Discount System
- 10% discount on orders of Rs. 500 or more
- 5% discount on orders of Rs. 250 or more
- No discount on orders below Rs. 250

## Technologies Used
- Python
- VS Code

## How to Run
1. Install Python on your computer.
2. Download or clone this project.
3. Open the project folder in VS Code.
4. Open the terminal and run:

```bash
python smart_canteen_billing.py
```
